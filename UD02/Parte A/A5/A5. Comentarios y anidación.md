# A5. Comentarios y anidación
### Un aviso de ciberseguridad tiene dos errores. Encuéntralos y corrígelos.

```
<!- Revisar el texto antes de publicar ->
<p>Tu contraseña debe tener <strong><em>al menos 12 caracteres</strong></em>.</p>
```

> El primer error estaría ya en la primera línea, comienza mal y debería ser < !-- y después cerrarse con -->. También, en las etiquetas < strong> y < em> están cerradas en el orden incorrecto y se debería cerrar primero la última que se escribió seguida de la primera que se escribió.

Código corregido:
```html
<!-- Revisar el texto antes de publicar -->
<p>Tu contraseña debe tener <strong><em>al menos 12 caracteres</em></strong>.</p>
