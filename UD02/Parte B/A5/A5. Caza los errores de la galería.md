# A5. Caza los errores de la galería
## Este código es de la galería de un viaje de fin de curso y tiene fallos (al menos 5). Anótalos y escribe la versión corregida.

```html
<!DOCTYPE html>
<html>
<head>
<meta charset="utf-8">
<title>Mi galería</title>
</head>
<body>
<h1>Mi viaje de fin de curso</h1>
<img>src="playa.jpg" alt="Playa al atardecer"</img>
<img src="monte.jpg" style="width=300px; height=200px;">
<a href=https://www.wikipedia.org target="_blank">Más información sobre el destino
</body>
</html>
```

> Error 1: La etiqueta ```<body>``` no está abierta antes del contenido.
> 
> Error 2: La primera etiqueta ```<img>``` está mal escrita, ```src``` y ```alt``` deberían estar dentro de ella.
> 
> Error 3: La etiqueta ```<img>``` es una etiqueta vacía y no debe cerrarse con ```</img>```.
> 
> Error 4: En el atributo ```style```, las propiedades CSS deberían separar el nombre y el valor con ```:``` y no con ```=```.
> 
> Error 5: El valor del atributo ```a``` debería ir entre comillas.
> 
> Error 6: Falta cerrar el enlace con ```</a>```.

> Código corregido :

```html
<!DOCTYPE html>
<html>
<head>
<meta charset="utf-8">
<title>Mi galería</title>
</head>
<body>
<h1>Mi viaje de fin de curso</h1>
<img src="playa.jpg" alt="Playa al atardecer">
<img src="monte.jpg" alt="Paisaje de montaña" width="300" height="200">
<a href="https://www.wikipedia.org" target="_blank">
Más información sobre el destino
</a>
</body>
</html>
```
