## A2. ¿Qué pasa al hacer clic?

### Caso A

```html
<!-- Caso A -->
<a href="#precios">Ver precios</a>
<h2 id="precios">Precios</h2>
```

> **¿Qué pasa al hacer clic?** El navegador salta al encabezado «Precios» de esa misma página porque el enlace apunta a `id="precios"`.

### Caso B

```html
<!-- Caso B -->
<a href="#Precios">Ver precios</a>
<h2 id="precios">Precios</h2>
```

> **¿Qué pasa al hacer clic?** El enlace no puede encontrar el destino porque `Precios` y `precios` son identificadores distintos. Las mayúsculas y minúsculas importan.

### Caso C

```html
<!-- Caso C -->
<a href="guia.html#instalacion">Ir a la instalación</a>
```

> **¿Qué pasa al hacer clic?** Se abre `guia.html` y, si esa página contiene un elemento con `id="instalacion"`, el navegador salta a esa sección.
