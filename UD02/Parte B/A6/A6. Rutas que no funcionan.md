# A6. Rutas que no funcionan

```text
proyecto/
├── index.html
├── contacto.html
├── apuntes.pdf
└── imagenes/
    ├── logo.png
    └── equipo.jpg
```

### Suponiendo que el código está en index.html, indica cuáles funcionan y cuáles no, y corrige las que fallen:

```html
<img src="logo.png" alt="Logo">
<img src="imagenes/equipo.jpg" alt="Equipo">
<a href="Contacto.html">Contacto</a>
<a href="apuntes.pdf">Apuntes</a>
<a href="imagenes/apuntes.pdf">Apuntes</a>
<img src="imagenes/equipo.png" alt="Equipo">
```

| Código | ¿Funciona? | Explicación / corrección |
|---|:---:|---|
| `<img src="logo.png" alt="Logo">` | No | `logo.png` está dentro de `imagenes`. Ruta correcta sería: `imagenes/logo.png`. |
| `<img src="imagenes/equipo.jpg" alt="Equipo">` | Sí | La imagen se encuentra en la carpeta `imagenes`. |
| `<a href="Contacto.html">Contacto</a>` | No | El archivo se llama `contacto.html` con minúscula. Se tiene que usar `<a href="contacto.html">Contacto</a>`. |
| `<a href="apuntes.pdf">Apuntes</a>` | Sí | `apuntes.pdf` está junto a `index.html`. |
| `<a href="imagenes/apuntes.pdf">Apuntes</a>` | No | No hay ningún archivo `apuntes.pdf` dentro de `imagenes`. Se usa `<a href="apuntes.pdf">Apuntes</a>`. |
| `<img src="imagenes/equipo.png" alt="Equipo">` | No | El archivo se llama `equipo.jpg`, no `equipo.png`. Se usa `<img src="imagenes/equipo.jpg" alt="Equipo">`. |
