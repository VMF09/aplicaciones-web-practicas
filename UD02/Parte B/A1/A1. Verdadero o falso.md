# Actividad 1.
## Verdadero o falso ( corrige las falsas )

| N.º | Afirmación | V / F | Corrección |
|---:|---|:---:|---|
| 1 | La etiqueta `<img>` se cierra con `</img>`. | F | `<img>` es una etiqueta vacía que no necesita etiqueta de cierre. |
| 2 | El atributo `alt` muestra un texto si la imagen no se puede cargar. | V | |
| 3 | Para dar ancho y alto a una imagen se recomienda usar `style` en lugar de `width` y `height`. | F | Los atributos `width` y `height` pueden usarse para indicar sus dimensiones. |
| 4 | La propiedad `float` permite que una imagen flote a la izquierda o a la derecha del texto, o que no flote. | V | |
| 5 | El rótulo de un enlace solo puede ser un texto. | F | El contenido de un enlace también puede incluir otros elementos, por ejemplo: una imagen. |
| 6 | `target="_blank"` hace que el enlace se abra en una pestaña nueva. | V | |
| 7 | Por defecto, un enlace ya visitado se ve azul y uno por visitar, morado. | F | Los enlaces no visitados suelen verse azules y los visitados son morados por defecto. |
| 8 | Un enlace relativo escribe la URL completa, incluido el dominio. | F | Un enlace relativo indica una ruta desde la ubicación del documento actual y no incluye el dominio. |
