# A4. Estilos rotos.
### El community manager de un streamer ha escrito estas líneas para el banner de su canal. Ninguna se ve como debería. Explica qué falla en cada una y corrígela.

```
<h1 style="color:red font-size:40px;">Directo esta noche</h1>
<p style="text-align=center;">Estreno de temporada</p>
<p style="background-color:yellow;">Sorteo de una tarjeta gráfica<p>
```

> En la primera linea, el style del < h1>, faltaría un punto y coma entre color:red y font-size.  En la segunda linea, el primer < p>, se usa = después del text-align pero debe separarse propiedad y valor con dos puntos.  Y en el último < p>, la etiqueta de cierre estaría mal escrita porque se repite < p> en vez de cerrarlo con < /p>.

Código corregido:
```html
<h1 style="color:red;font-size:40px;">Directo esta noche</h1>
<p style="text-align:center;">Estreno de temporada</p>
<p style="background-color:yellow;">Sorteo de una tarjeta gráfica</p>
```
