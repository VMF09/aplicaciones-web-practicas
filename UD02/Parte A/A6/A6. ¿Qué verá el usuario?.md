# A6. ¿Qué verá el usuario?
### Sin abrir el navegador, dibuja o describe lo que se mostrará. Después compruébalo y anota si acertaste.
```html
<h1>Resumen de la jornada</h1>
<p>Ha ganado el equipo local.<br>El rival se despide del torneo.</p>
<hr>
<h4>Próximo partido</h4>
<p>Sábado a las 18:00</p>
```

> Como encabezado principal, se verá "Resumen de la jornada", después se vería un párrafo con el texto "Ha ganado el equipo local." y en la siguiente linea "El rival se despide del torneo." porque hay un salto que se produce con < br>.  También se verá una línea horizontal que es creada con < hr>, un encabezado de nivel 4 que muestra "Próximo partido.".  En el último párrafo se podrá ver el texto "Sábado a las 18:00."
