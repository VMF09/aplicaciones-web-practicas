# Actividad 1.
## Verdadero o falso ( corrige las falsas )
#### En el grupo de clase se ha montado un debate. Decide quién tiene razón y, si la frase es falsa, reescríbela para que sea correcta.

| N.º | Afirmación | V / F | Corrección si es falsa |
| ----| ---------- | ----- | ---------------------- |
|  1  | "HTML es un lenguaje de programación como Python: sirve para hacer cálculos y tomar decisiones." | Falso | HTML es un lenguaje marcado. |
|  2  | "La etiqueta < br> no necesita etiqueta de cierre." | Verdadero |  |
|  3  | "El valor de un atributo siempre se escribe entre comillas." | Falso | Los valores de algunos atributos pueden escribirse sin comillas, aunque se recomienda usar comillas. |
|  4  | "Los atributos de una etiqueta se escriben en la etiqueta de cierre." | Falso | Los atributos se escriben en la etiqueta de apertura. |
|  5  | "El texto de <title> aparece en la pestaña del navegador." | Verdadero |  |
|  6  | "< strong> y < b> se visualizan igual." | Verdadero |  |
|  7  | "Todo lo que escribimos dentro de <head> se ve en la página." | Falso | < head> es lo que contiene la información y los metadatos de la página, el contenido visible suele escribirse dentro de < body>. |
|  8  | "La etiqueta < hr> se cierra con < /hr>." | Falso | < hr> es una etiqueta vacía y no lleva ninguna etiqueta de cierre. |
|  9  | "Un comentario HTML (<!- - ... -->) se muestra en pantalla como una nota gris." | Falso | Un comentario HTML no aparece en la páquina que ve el usuario. |
|  10  | "< span> crea un bloque de texto que siempre empieza en una línea nueva." | Falso | < span> es un contenedor en línea y no empieza necesariamente en una línea nueva. |
