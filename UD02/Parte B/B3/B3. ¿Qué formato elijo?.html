Para una foto de vacaciones con muchos colores, recomendaría el formato JPEG, con extensión .jpg o .jpeg. Es perfecto para fotografías y permite reducir el tamaño del archivo.

Para un logo con algún fondo transparente, recomiendo PNG, con extensión .png. Este formato conserva las zonas transparentes del logo.

Para un icono que se vea nítido en cualquier tamaño, recomiendo SVG, con extensión .svg. Al ser un formato vectorial, este se puede ampliar sin que pierda calidad.

Para una animación corta tipo meme o sticker, recomiendo GIF, con extensión .gif. Este formato permite crear animaciones sencillas.

Para el icono de la pestaña del navegador, recomiendo ICO, con extensión .ico. Es un formato habitual para los iconos de las páginas web.
