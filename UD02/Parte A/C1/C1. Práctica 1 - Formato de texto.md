# Parte C. Práctica 1. Formato de texto

## Reflexión previa

### 1. ¿Qué etiqueta usarás para cada párrafo y qué propiedad CSS consigue la justificación?

Se utiliza la etiqueta `<p>` para cada uno de los 8 párrafos.

La propipiedad CSS que consigue la justificación del texto es la siguiente:

```css
text-align: justify;
```

---

### 2. Los comentarios de los personajes irán en cursiva y los sentimientos en color y negrita. ¿Qué etiquetas sirven para marcar solo una parte de un párrafo?

Para poner en cursiva una parte de un párrafo se usaría `<i>`.

Las etiquetas que sirven para marcar solo una parte de un párrafo es `<span>` y se puede juntar con estilos CSS y la etiqueta `<b>`.

Ejemplo:

```html
<p>
    Julio dijo <i>"No tengo miedo"</i> y se sintió
    <span style="color: red;"><b>muy valiente</b></span>.
</p>
```

---

### 3. Un mismo sentimiento debe tener siempre el mismo color. ¿Cómo evitas equivocarte?

Se podría hacer una lista para asociar cada sentimiento con un color.

Por ejemplo:

- Valentía = rojo
- Bondad = verde
- Tristeza = azul
- Alegría = naranja
- Esperanza = violeta

De esta forma se podrá utilizar siempre el mismo color para el mismo sentimiento en todo el documento sin ninguna equivocación, si se añadieran más sentimientos, también se tendrían que poner en la lista junto a su color correspondiente.
